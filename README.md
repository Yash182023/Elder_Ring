# Elder Ring

## Overview
The **Elderly Care Coordination Platform** is a **SaaS-based solution** designed to assist elderly users, caregivers, and healthcare providers in managing health, appointments, and essential services. The platform also includes an **e-commerce marketplace** for purchasing medical supplies and caregiving services.

## Features
- **User Management:** Elderly users, caregivers, and healthcare providers with role-based access.
- **Health Tracking:** Medications, and appointments.
- **Service Booking:** Schedule caregiving, transportation, and telehealth consultations.
- **E-Commerce Marketplace:** Purchase medical supplies and assistive devices.
- **Notifications & Alerts:** Medication reminders, appointment alerts, and health updates.
- **Secure Payments:** Integrated payment gateway for service and product purchases.

## Tech Stack
- **Frontend:** React, TypeScript, Sass
- **Backend:** Node.js, Express, TypeScript
- **Database:** Mysql
- **Authentication:** JWT-based authentication


## Installation
### Prerequisites
Ensure you have the following installed:
- Node.js (v18+)
- npm (v9+)
- MySQL

### Setup & Run
1. **Clone the repository:**
   ```sh
   git clone https://github.com/Yash182023/Elder_Ring.git
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Start the development server:**
   ```sh
   npm run dev
   ```

4. **Start the backend server:**
   ```sh
   node server.js
   ```

5. **Access the application:**
   - Frontend: `http://localhost:3000`
   - Backend API: `http://localhost:3001/api`
